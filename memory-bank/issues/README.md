# Issue Reports

Each reported defect has its own folder under this directory:

```text
memory-bank/issues/
└── ISS-YYYY-NNN/
    ├── issue.md
    └── evidence/
        ├── README.md
        └── {screenshots-logs-recordings-and-other-evidence}
```

The Issue Agent assigns the next unused yearly identifier and creates each folder from `.specsmd/aidlc/templates/issues/issue-template.md`. Keep evidence with its report, list every file in the issue's evidence table, and redact secrets, credentials, tokens, and unnecessary personal or financial data before saving it.
